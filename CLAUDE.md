# CLAUDE.md

## Project overview

JobPilot is a job-search / recruiting SaaS product in its earliest stage. The codebase is
currently the unmodified **Sassio** Next.js marketing template (AliThemes, v2.0), which was
purchased as a starting point and extracted into the repo root. Nothing product-specific has
been built yet — the 65 routes under `app/` are template demo pages, not JobPilot features.

## Layout of the code

- `app/` — App Router. One directory per demo page (`about/about-1` … `portfolio/portfolio-list-10`).
  `app/layout.tsx` is the root layout: it imports the three global stylesheets and the
  `Work_Sans` Google font.
- `components/layout/Layout.tsx` — the page shell. Takes `headerLayout` / `footerLayout` numbers
  (1–11) and switches between `Header1..Header11` / `Footer1..Footer11`. Every page composes
  `<Layout>` plus section components.
- `components/sections/` — page sections, grouped by `homepage/` and `blog/`.
- `components/elements/`, `components/slider/`, `components/portfolio/` — smaller shared pieces.
- `public/css/` — `vendors.css`, `animate.min.css`, `main.css`. All visual styling lives here.
- `public/img/` — ~24 MB of template imagery, organised by page (`home-1/`, `about-1/`, …).

## Conventions

Match the surrounding code rather than reformatting it:

- **4-space indentation**, and **no trailing semicolons** in most files (a few stray ones exist).
- Path alias `@/*` maps to the repo root — `import Layout from '@/components/layout/Layout'`,
  and even CSS is imported that way (`'@/public/css/main.css'`).
- `export default function ComponentName()`, PascalCase, one component per file.
- Props are typed with a local `interface Props { ... }` above the component.
- `'use client'` (single quotes) sits at the top of the 57 of 215 `.tsx` files that need
  browser APIs, hooks, or animation libraries. Everything else stays a Server Component.
- Styling is done by writing class names that already exist in `main.css` (e.g.
  `masthead__title`, `wow animate__animated animate__fadeInUp`). Prefer reusing an existing
  class over adding new CSS.
- Images go through `next/image`; the template's habit is
  `width="0" height="0" sizes="100vw"` with a `style` override.

### Known template quirks

- `components/layout/Header/Header6..tsx` has a **double dot** in its filename and is imported
  as `'./Header/Header6.'`. It is not a typo to "fix" casually — renaming it means updating
  the import in `Layout.tsx`.
- `Layout.tsx` uses `Number` (the boxed type) instead of `number` for its props.
- Its `useEffect` has no dependency array and adds a `scroll` listener on every render.
- `next@14.1.3` has a published security advisory. Upgrading is worth doing before this goes
  anywhere public; it is a deliberate open item, not an oversight.

## Commands

```bash
npm install       # 424 packages
npm run dev       # dev server on :3000
npm run build     # production build — currently clean, 69 static routes
npm run lint      # next lint — currently clean, 0 warnings
```

Before finishing any change, run `npm run build` **and** `npm run lint`. Both pass today, so
any failure is something the change introduced.

## Do not touch

- `sassio-saas-software-app-nextjs-template-2024-06-11-00-49-16-utc.zip` — the pristine
  purchased template, kept tracked as the reference copy. Never edit or delete it.
- `public/css/*.css` — vendor/template CSS. Add a new stylesheet instead of editing these.
- `public/img/**` — template assets; replace with JobPilot artwork deliberately, not in passing.
- `next-env.d.ts` — generated by Next.js, and gitignored.
- `package-lock.json` — change it only via `npm` commands, never by hand.
- `.next/`, `node_modules/` — build output and dependencies.

## Working agreements

- Scope work to one route or one component at a time; this repo has 65 demo pages and a broad
  sweep across all of them is almost never what is wanted.
- For anything destructive or wide-reaching (deleting demo pages, swapping the CSS system,
  upgrading Next.js), lay out the plan and get agreement before editing.
- Deleting unused template pages is expected eventually — but confirm which ones first.
